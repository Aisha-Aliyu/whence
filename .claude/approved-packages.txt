# The package check (.claude/hooks/check_packages.py) blocks packages younger than

# malware report in OSV.
#

# request is reviewed and merged, and it can take a few minutes to show. Only Aisha
# adds lines. Claude never edits this file.

# pypi/<name>==<version>  # why it cannot wait, YYYY-MM-DD
