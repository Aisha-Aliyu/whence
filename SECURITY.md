# Security policy

## Report a vulnerability

Please report security problems privately. Do not open a public issue.

1. Open the Security tab of this repository.
2. Select "Report a vulnerability".
3. Describe the problem, how to reproduce it, and what an attacker could do with it.

You will get a reply within 7 days and updates until the problem is fixed. If you want credit, you will be named when the fix ships. Please allow 90 days for a fix before you disclose the problem publicly.

## Scope

In scope: the code in this repository, and the Whence web app and API once they are live.

Out of scope: denial of service through traffic volume, social engineering, spam, and automated scanner reports without a working proof of concept.

## Good faith research

We will not pursue legal action against research done in good faith under this policy. Do not access, change or delete other people's data, and stop as soon as you have confirmed a problem.

## Supported versions

Only the latest version on the `main` branch receives security fixes.
